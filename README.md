# Python宠物信息管理系统简介

## 核心功能
- **宠物管理**：记录和更新宠物的基本信息，如品种、年龄、性别等。
- **健康记录**：记录宠物的健康检查和疫苗注射情况。
- **疫苗接种管理**：管理宠物的疫苗接种记录，包括接种时间、疫苗类型等。
- **寄养服务**：提供宠物寄养信息的录入和管理。
- **用户管理**：对系统用户进行注册、登录和权限控制。
- **系统管理**：维护系统设置，包括日志记录、数据备份等。

## 适用场景
- 宠物医院
- 宠物店
- 宠物寄养机构
- 宠物爱好者社区
- 需要宠物信息管理的个人或组织

## 技术特点
- **技术框架**：采用 Django 框架构建，保证系统的高效性和稳定性。
- **数据库**：使用 SQLite 数据库，确保数据存储的安全性和便捷性。
- **前端技术**：结合 HTML、CSS 和 JavaScript，实现友好的用户界面和丰富的交互功能。
